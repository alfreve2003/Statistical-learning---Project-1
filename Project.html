0. Introduction

The aim of this assignment is to study how noise affects image data and classification performance, and to investigate whether Principal Component Analysis (PCA) can be used to obtain lower dimensional representations and reconstruct less noisy images. In this assignment, we are working with the MNIST dataset, which consists of grayscale images of handwritten digits (0–9), each of size 28 × 28 pixels. We are going to generate noisy versions of the images using the multivariate normal distribution, apply PCA, and compare the performance of different classification methods.

As there will be several processes which contain some randomness or stochasticity, in order to guarantee the results reproducibility, it is necessary to set a seed. In our case, it will be 42.

seed <- 42

Matrix representation models the image as a 28 x 28 matrix. On the other hand, vector representation just takes all the pixels and puts them in a vector living in \(\mathbb{R}^{28^2} = \mathbb{R}^{784}\) by placing the rows of the matrix one after another. Both are equivalent, since they contain exactly the same information. The only difference is that the vector representation does not explicitly take into account the spatial structure of the image (which pixels are neighbours of each other): two horizontally adjacent pixels are consecutive elements of the vector, but two vertically adjacent pixels are 28 positions apart. As a consequence, methods such as PCA treat the 784 pixels as ordinary variables, without using the fact that nearby pixels tend to have similar values.

Part 2. Noise generation using the multivariate normal distribution.

2.1

In this section we will add random noise to our training dataset. We will generate three noise levels using a multivariate normal distribution. Given the vector \(\mathbf{x}_i\in\mathbb{R}^784\) corresponding to image \(i\), the noisy version will be: \[\mathbf{x}_i^* = \mathbf{x}_i + \epsilon_i,\] where \(\epsilon_i\) is obtained from the distribuition \(\mathcal{N}_784(\mathbf{0},\sigma^2\mathbf{I}_784)\).

As the noise has mean 0, adding the noise to the images will not make them any brighter or darker, on average

The covariance matrix of the noise distribution, \(\Sigma = \sigma^2\mathbf{I}_784\), is a scalar matrix. This implies the noise components for each pixel are uncorrelated and identically distributed. Furthermore, as the noise generated follows a multivariate normal distribuition, the components corresponding to each pixel will be independent from each other.

The marginal distribution of each noise component is therefore \(\mathcal{N}(0,\sigma^2)\).

To model three different noise levels, we will generate noisy versions using three different values of \(\sigma\). To decide which values of \(\sigma\) are apropiate, we will consider the Signal to Noise ratio, which is commonly defined as: \[SNR=\frac{\bar{\mathbf{X}^2}}{\sigma^2},\] where \(\bar{\mathbf{X}^2}\) represents the mean value of the signal squared, in this case, of the pixels.

As the images are mostly white background, the mean square value will be dragged towards 0, which will result in lower noise than we want. To avoid this, we will calculate the mean square of the pixels which are not completely white.

A signal to noise ratio greater than one corresponds to low noise, or a clean signal. Conversely, a signal to noise ratio lower than 1 corresponds to a noisy image. We will aim to have an \(SNR\) of 2 for the low noise signal, 1 for the medium noise signal and 0.5 for the high noise signal.

musq <- mean(X_train[X_train!=0]^2) # Calculate the square mean of the non zero pixels
sigmaLow <- sqrt(musq/2)
sigmaLow
## [1] 0.5411652
sigmaMedium <- sqrt(musq)
sigmaMedium
## [1] 0.7653232
sigmaHigh <- sqrt(musq/0.5) 
sigmaHigh
## [1] 1.08233

We obtain the following values for \(\sigma\). Low noise, \(\sigma = 0.5411652\), medium noise, \(\sigma = 0.7653232\), and high noise, \(\sigma = 1.08233\).

2.2

We will now generate the noisy datasets. To ensure repoducibility we set the seed once before generating the noise. This ensure the noise generated is the same on every execution while being different for every pixel in every image.

As the generated noise could make the pixel value fall out of the \([0,1]\) interval, we will clip the values after the noise has been added. Therefore if a certain pixel will end up with a value lower than 0, we set it to 0, and it its value will be greater than 1, we set it to 1.

set.seed(seed) # Seed for reproducibility

m = ncol(X_train) # Number of pixels

# Initialize copies of the dataset
X_low <- X_train
X_medium <- X_train
X_high <- X_train

# Loop over the images
for (i in 1:n_train){
  # Noise generation
  epsLow <- rnorm(m, mean = 0, sd = sigmaLow)
  epsMedium <- rnorm(m, mean = 0, sd = sigmaMedium)
  epsHigh <- rnorm(m, mean = 0, sd = sigmaHigh)
  # Adding noise to the images
  X_low[i,] = X_low[i,] + epsLow
  X_medium[i,] = X_medium[i,] + epsMedium
  X_high[i,] = X_high[i,] + epsHigh 
}
# Clipping values to [0,1]
X_low <- pmin(pmax(X_low,0),1)
X_medium <- pmin(pmax(X_medium,0),1)
X_high <- pmin(pmax(X_high,0),1)
